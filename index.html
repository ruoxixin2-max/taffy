API CONNECTION

地址可直接填写 Base URL（如 /v1）；聊天会自动补 /chat/completions，拉模型自动走 /models。也支持填写完整接口。
关闭时 Key 只保留到本页刷新前。公开部署网页时不要把正式密钥写进源码。

IMAGE GENERATION API

会根据当前生图 Endpoint 自动尝试常见 /models 接口；不支持模型枚举的服务仍可手动填写。
作为全局画面偏好，自动与角色生成的图片描述合并。
支持原生 negative_prompt 的接口会单独发送；其他接口会附加到 Prompt 中。

VOICE / TTS API

会根据当前语音 Endpoint 自动尝试常见 /models 接口；ElevenLabs 会自动使用 xi-api-key。
MiniMax 已区分中国版与国际版：国内默认 api.minimaxi.com，国际默认 api.minimax.io。ElevenLabs 的 Endpoint 需要包含 Voice ID，选择服务商时会自动生成。

STORAGE

图片媒体改用 IndexedDB 保存，localStorage 只保留轻量文字与引用。旧 Base64 图片可一键迁移；不会删除仍被使用的图片。

PHONE DATA BACKUP

完整导出整部“小手机”的本地数据：联系人、聊天、User 面具、世界书、备忘录、美化、朋友圈/小红书、纪念日、外卖、游戏、直播、Live2D、关系网、主动行为、通话，以及 Chat / Image / Voice API 配置与 Key、MCP Token。注意：导出的 JSON 含明文密钥，请只保存到私人位置，不要分享。

CHAT BACKUP

导出可完整恢复聊天环境的 JSON：联系人、聊天记录、User 面具、世界书、聊天总结、关系便签、未读、聊天主题、表情包、朋友圈/小红书，以及 Chat / Image / Voice API 配置与 Key、MCP Token。注意：文件含明文密钥，请勿分享。

CONTEXT MEMORY

达到阈值后，在角色回复前自动把较早聊天更新成长期总结；原聊天记录不会删除。
推荐：40 条触发、保留最近 18–24 条。总结会保留人物关系变化、承诺、冲突、重要事实、称呼、偏好与未解决事项。
